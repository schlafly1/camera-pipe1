# TrafficCamNet Transformer Lite (RT-DETR, resnet50) — traffic-domain detector.
# Replaces the resnet18 TrafficCamNet PGIE (pgie_config_multi.yml).
# Output slots (verified 2026-09-30 by running the engine offline on Thor
# snapshots, tools/rtdetr_offline.py): the model emits FIVE class scores per
# query: 0=background (unused) 1=bicycle 2=car 3=person 4=road_sign (4 by
# elimination; it fires on the cameras' OSD timestamp text). The old
# 4-class reading (0=Car 1=RoadSign 2=Person 3=Bicycle) was wrong and
# mislabeled every detection. detector_labels.txt must have exactly
# num-detected-classes lines; pipeline_multi.py refuses to start otherwise
# (and if the ONNX pred_logits width differs).
# Preprocessing/parser values taken from NVIDIA's DS 9.1 RT-DETR template
# (deepstream-tracker-3d-multi-view/config_templates/config_pgie_rt_detr.txt).
